# AE 中英文切换器界面精简与图标设计

日期：2026-08-08

## 目标

在不改变现有扫描、语言判定、文件安全和 AE 运行阻断逻辑的前提下，将主窗口改成一眼即可操作的精简工具，并把用户提供的紫色“中 / En”图片接入为正式 macOS App Icon。

## 主窗口

- 单窗口固定为约 `420 × 260 pt` 的紧凑布局，不再使用滚动区域。
- 左上角显示 `AE 语言切换`。
- 右上角同时显示 `中文  |  English`。当前有效语言使用紫蓝色高亮、加粗并带小圆点；另一项为次要灰色。两项仅展示状态，不可点击。
- 中央只保留一个大号主按钮：
  - 当前为简体中文时显示 `切换到 English`。
  - 当前为 English 时显示 `切换到中文`。
  - 未完成扫描时显示 `正在扫描…` 并禁用。
  - 未找到 AE 时显示 `未检测到 After Effects` 并禁用。
- 底部右侧保留 `重新扫描` 按钮；扫描中显示小型进度指示。
- 底部左侧只在需要时显示一行简短状态，例如切换成功或扫描失败；没有消息时不占据视觉焦点。

## 隐藏内容

主界面不再显示：

- AE 版本选择器；
- 版本号、构建号和安装路径；
- 中文资源、英文资源和运行状态明细；
- “语言设置会影响当前用户的全部 AE 版本”警告卡片；
- 常驻帮助按钮和常驻中文资格说明。

底层仍扫描全部安装，并继续按版本号从高到低选择最高版本完成中文资格判断。语言标记本身仍是当前用户级全局设置。

## 交互与异常

- 单按钮的目标语言由当前有效语言自动决定。
- AE 正在运行时按钮仍可点击；点击后由现有新鲜进程检查阻止文件修改，并弹出“请先退出 AE”的提示。
- 缺少中文资源、系统首选语言不是简体中文、标记文件异常、扫描失败等情况继续通过现有原生弹窗说明，不在主界面堆叠说明文字。
- 切换成功后刷新状态，按钮文案和右上角高亮立即反转；提示用户下次启动 AE 生效。
- 无法归类为中文或 English 的系统默认语言状态时，两项均不高亮，主按钮仅在能确定安全目标时启用。

## App Icon

- 源图：用户提供的 `/var/folders/zy/n5kt51xx3yz_0qxd48rmfdkm0000gn/T/codex-clipboard-dc371cb5-8c95-4714-b4cd-b7d5cb1974dd.png`。
- 保留紫色渐变、“中 / En”卡片和双向箭头，不重新绘制或改变画面内容。
- 将源图归一化为 `1024 × 1024` 正方形母版，再生成 macOS iconset 所需的 `16、32、64、128、256、512、1024 px` PNG 变体。
- 使用 `iconutil` 生成 `AppIcon.icns`，在 `Info.plist` 中声明 `CFBundleIconFile`，并由打包脚本把图标复制进 `.app/Contents/Resources`。
- 每次重新打包后验证 `.icns` 存在、plist 有效、应用签名有效。

## 代码边界

- `ContentView.swift` 只负责精简布局、状态呈现和单按钮目标计算。
- `AppModel` 继续负责扫描、语言判定、运行进程检查、切换和弹窗，不改变文件安全策略。
- 图标制作由独立资源脚本完成；打包脚本只消费生成好的 `.icns`，避免把图像处理逻辑混入应用代码。

## 测试与验收

- 新增单按钮目标测试：中文状态指向 English，English 状态指向中文，未知/未扫描状态无目标。
- 保留并运行现有 36 项核心测试，确认语言切换和竞态安全不回退。
- Debug 与 Release 构建成功。
- 打包后的窗口只呈现标题、双语言状态、一个主按钮、简短状态和重新扫描。
- 打包后的应用包含 `AppIcon.icns`，Dock/Finder 能显示新图标。
- `plutil` 与 `codesign --verify --deep --strict` 通过。
- 实机只读启动不修改真实 `ae_force_english.txt`。

## 暂不包含

- 可点击的中文/English 分段选择器；
- 重新展示版本和安装详情；
- 菜单栏模式；
- 新的文件切换机制；
- Developer ID 签名、公证或通用二进制构建。
